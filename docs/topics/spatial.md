# 通道异构的四种解法

> EEG 换一台设备就是另一套电极布局——通道适配能力直接决定基础模型能不能"跨设备"。六篇论文给出四种代表性方案。

## 四种方案对比

| 方案 | 论文 | 机制 | 优点 | 局限 |
|---|---|---|---|---|
| **① 通道 embedding 表** | [BIOT](../papers/2026-09/0918-biot.md) | 每个通道名一个可学习向量，逐通道切段后相加 | 简单；缺通道直接丢 token | 表大小受训练时见过的通道限制 |
| **② 10-20 系统空间编码** | [LaBraM](../papers/2026-09/0918-labram.md) / [NeuroLM](../papers/2026-09/0918-neurolm.md) | 全系统电极的空间 embedding 列表，按名字索引 | 统一坐标系，预训练可收敛（LaBraM 消融：去掉 SE 不收敛） | 非标准设备（ear-EEG 等）无对应 embedding |
| **③ 单通道独立建模** | [TFM-Tokenizer](../papers/2026-09/0918-tfm-tokenizer.md) / [BrainGPT](../papers/2026-09/0918-braingpt.md)（电极级） | tokenizer/训练样本以单通道为单位 | **天然 device-agnostic**，任意电极组合 | 丢失跨电极同步信息，需下游补空间整合 |
| **④ 图结构整合** | [BrainGPT](../papers/2026-09/0918-braingpt.md)（TEG） | 全电极建一张可学习图，样本只激活子图 | 多任务共享 + 任意配置统一训练 | 仅下游阶段，空间信息不在预训练中 |

## 方案③的代价与补偿

单通道建模是最激进的方案：把多电极 EEG 拆成独立样本（BrainGPT 样本量 ×E 倍膨胀到 3750 万），换来的是对任意采集设备的兼容性。但跨电极的空间关系在预训练中完全丢失，所以：

- **BrainGPT** 在下游用 TEG（任务共享电极图）补回空间：每条电极序列末尾接可学习 token 聚合出电极表示，再注入全电极图做 GAT 注意力（子图激活 + mask）；
- **TFM** 在下游把各通道 token 展平后加通道/位置 embedding 过注意力。

这构成一个共同范式：**"单通道学时间 + 下游学空间"的渐进式时空解耦**（BrainGPT 的官方说法）。

## TEG 的多任务共享机制（易误解点）

图本身不存储任务信息——**多任务信息来自"共享参数被多个任务的梯度共同更新"**：

- 节点向量 h_m = **V_m（可学习电极原型）** + z_j（样本内容）；
- joint 训练时，同一电极 V_m 同时接收所有涉及该电极的任务的梯度 → V_m 成为跨任务的电极记忆；
- 推理时任务区分靠：输入电极集决定激活哪个子图（β mask）+ 任务专属 head；
- 论文证据：joint 训练全面优于 separate，数据量最小的任务受益最大（MW 仅 4K 样本 +3.9%，SS 42K 样本 +0.9%）——共享节点相当于小任务的隐式数据增强。

若两任务电极集完全不相交，空间层面的共享就只剩 GAT 权重，多任务增益会大幅缩水。EEG 主流电极高度重叠（同源于 10-20 系统），所以这一设计在 EEG 里特别划算。

## 跨设备能力的分水岭

TFM 的 ear-EEG（EESM23）实验是张试金石：睡眠分期任务，采集设备、通道配置与预训练完全不同，仅 ~8K 标注样本微调——

- TFM-Tokenizer：0.4148 balanced acc（比 BIOT/LaBraM 高 14%）✓
- BIOT / LaBraM：可跑但明显更弱
- **EEGPT：无法参与**——固定 58 通道布局的空间 embedding 无法映射到 ear-EEG 通道

结论：**通道适配方案决定了模型的应用边界**。要做可穿戴、消费级 EEG（干电极、耳部、少导联），方案③（单通道独立）是目前最稳的路线。
