# 语音模型专题：脑信号 → 语音

> 站内第三条方法轴线：与「基础模型轴线」（EEG → 任务表示）和「生成轴线」（噪声 → EEG）对望，这条线做 **EEG/MEG → 语音**。已精读两篇——[Défossez 语音解码](../papers/1102-defossez-speech.md)（NMI 2023，轴线源头，检索范式）与 [SSM2Mel](../papers/1102-ssm2mel.md)（arXiv 2025，mel 谱回归范式）；EEG-to-Text 生成式一系（DeWave / EEG2TEXT / DELTA）已下载待读。本页按 **Tokenization / Pretraining / 下游任务** 三段横读。

## 全景

| | Défossez（NMI 2023） | SSM2Mel（arXiv 2025） | 待读：DeWave / EEG2TEXT / DELTA |
|---|---|---|---|
| 任务 | 感知语音 **zero-shot 检索**（3s 片段，千余候选） | **连续 mel 谱回归** | EEG → **文本生成** |
| 模态与规模 | MEG+EEG，4 数据集 175 人 | EEG，SparrKULee 85 人 | — |
| 范式 | 卷积脑模块**对比对齐** wav2vec 2.0 | S4-UNet + Mamba/MHSA **监督回归** | RVQ / 离散词表 + 语言模型 |
| 代表成绩 | MEG 段级 top-10 **70.7%**（EEG 17.7%） | Pearson **0.069**（较 VLAAI +38%） | — |

## 一、Tokenization：脑信号端不切段，语音端选空间

### 脑信号端：两条连续路线

这条线没有基础模型线意义上的 tokenization——不切 1s patch、不建词表，脑信号以**连续特征序列**进模型：

| | Défossez | SSM2Mel | 对照：基础模型线 |
|---|---|---|---|
| 切段 | 不切。120Hz 连续卷积，以 3s 片段为样本单位 | 原始波形 → S4-UNet 局部预提取 → 下采样特征序列 | 1s / 250ms patch |
| 通道处理 | **空间注意力**：傅里叶参数化的头皮平滑函数（每轴 K=32 谐波），把任意导联布局重映射到固定 270 通道 | 不单独解通道，靠 **ESM 被试嵌入**调制 | 通道表 / 10-20 编码 / ACPE / codex book |
| 被试处理 | 每被试一个 270×270 的 1×1 卷积 | ESM 强度调制（消融 0.063→0.069） | 多被试联合训练少 |
| 位置编码 | 无显式 PE（膨胀卷积平移不变） | scaled positional encoding | 查表 / RoPE / 卷积生成 |

分工清楚：这条线的异构主要来自**被试**而非 montage（单个数据集内设备固定），所以空间注意力、被试层、ESM 都冲着个体差异去；基础模型线的异构来自跨数据集 montage，通道编码才是主战场。Défossez 有个意外发现：空间注意力这层原意是让一个模型跨四个数据集共享权重，结果本身就把精度抬了上去——平滑性地形先验的归纳偏置红利。

### 语音端：目标空间的三次试错

Défossez 的特征选择实验是这条线最重要的方法论结论，三级递进：

1. **直接回归 Mel**——失败。Mel 各维度重要性极不均衡（极低频与语音几乎无关、频带幅值差几个量级），L2 平等对待后输出被一个宽带不可分辨成分主导，谱图只是一团模糊能量轮廓，分不出词；
2. **对比 Mel**——把「逐维拟合」改成「可分辨性」（CLIP 式对比，只要求正确段在 batch 里排第一）：Gwilliams 上 top-10 从 12.4% 拉到 55.1%，**+42.7pp**；
3. **对比 wav2vec 2.0**——最好。用 56,000 小时语音自监督预训练的 wav2vec2-large-xlsr-53（末 4 层激活平均），全面胜过端到端学的 Deep Mel。

结论：**表征格式的选择题外包给自监督语音模型**——脑用什么格式编码语音是未解问题，但自监督语音特征的激活已被脑编码文献证明可线性映射到脑响应，对齐它是在借一个验证过的空间。

SSM2Mel 反着选 mel：它的任务就是**重建谱图本身**（可听、可反推语音），不做语义检索——目标不同，与 Défossez 不矛盾，是在回答另一个问题。

### 与 EEG 词表线的分野与合流

基础模型线用三轮（LaBraM → NeuroLM → TFM）把离散词表搬到**脑信号端**；这条线的离散单元在**语音/文本端**（wav2vec 特征、LLM 文本词表），脑端保持连续。2023 年起两条线开始合流：DeWave 首次把 EEG 波形离散成码再做文本翻译，DELTA 用 RVQ 多层词表接掩码语言扩散——词表线的技术正在被语音解码线吸收。

## 二、Pretraining：监督对齐与回归，没有自监督

这条线与基础模型线最大的范式差：**全部有监督**。基础模型线卷对比/掩码/自回归/生成四条自监督路线，是因为无标签可用；这条线存在（脑信号，语音）配对数据，范式因此完全不同。

- **对比对齐（Défossez）**：CLIP 式损失，但只做单向（脑 → 语音）、无温度参数，负例来自 batch。训练目标与下游评测是同一个操作的放大——训练时在 batch 负例里排第一，测试时在全部候选里排第一。脑端编码器从零训练，「预训练」的全部来源是语音端 wav2vec 2.0 的 56k 小时自监督：**把预训练外包给语音侧**；
- **监督回归（SSM2Mel）**：端到端拟合 mel 谱，无自监督、无预训练，纯吃配对数据；
- **大队列联合训练**：Défossez 性能随训练被试数单调上升，被试差异被压进一个 270×270 矩阵——被试特异性不必靠复杂预处理吸收，这是全文对站内最有迁移价值的工程结论。

数据经济学是两个世界的：配对录音每人 6–20 小时起步（MEG 更贵），175 人已属领域最大梯队——对比基础模型线 25000h 的无标注语料，「有没有标签」决定了这条线的范式上限。

## 三、下游任务：检索、回归、生成三种协议

| 协议 | 论文 | 指标 | 回答的问题 | 现状 |
|---|---|---|---|---|
| **检索** | Défossez | 段级 top-10 / 词级 top-1 | 脑信号能不能**认出**听到的语音 | MEG 70.7% / EEG 17.7%（top-10） |
| **回归** | SSM2Mel | Pearson / 谱图保真 | 脑信号能不能**重建**连续语音表征 | 0.069（mel 谱回归首个 Mamba 系） |
| **生成** | DeWave / EEG2TEXT / DELTA（待读） | CER / BLEU | 脑信号能不能**产出**文本 | EEG-to-Text 线，2026 出现可行性质疑 |

三个协议各有一个坑要记：

- **检索**的「zero-shot」成立前提是词表不重叠（word overlap 60–85%，即 15–40% 测试词训练没见过），引用时要带口径。MEG 与 EEG 的差距（70.7% vs 17.7%）在通道数、时长、被试数全部配平后依然显著（Mann-Whitney P < 10⁻⁶），是**模态差距**不是数据差距；最好被试 top-1 已过 80%；
- **回归**先问划分维度——SSM2Mel 的 80/10/10 论文未写明按被试还是按 trial 切，直接决定成绩可不可比（复现必查项）；
- **生成**最需要警惕可行性：EEG2Text-Feasibility（2026）专门用神经心理学启发的 benchmark 分析 EEG-to-Text 在真实场景是否成立——引用 2023–2024 年的 CER 数字前先看它。

**模态选择**是这条线绕不开的定位题：MEG 全面优于 EEG 且不是数据量问题（磁测量不受颅骨导电性模糊、空间定位准），但可穿戴化只有 EEG 一条路。

## 对新论文入库提示

读语音解码论文记四问：① 脑端怎么处理 montage 与被试（空间注意力 / 被试层 / ESM / 其他）？② 语音端目标空间选什么（mel / 自监督语音特征 / 离散单元）？③ 配对数据几人几小时、被试间还是被试内划分？④ 评测是检索 / 回归 / 生成的哪种，zero-shot 声称的词表重叠率是多少？
