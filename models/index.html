    模型对比#

    从 data/models.json（21 个模型条目）中选择 2–4 个模型并排对照。数值只在与协议条件相符时同表显示；跨论文条件不同可并列查看原报告，本页不做综合得分或默认排名。十四篇的叙事性对照见十四篇方法对比。

    使用规则#

    • 参数量按口径分组（总参数 / 激活 / encoder / tokenizer），来自各论文自报，口径见 comparison.md 规模节；
    • 权重状态：open = 官方开源；partial = 以项目页为准；none = 未放出；
    • 布局一栏描述模型对电极配置的假设（固定 10-20 / ACPE 非绑定 / query 压缩 / 坐标生成），是跨数据集泛化能力的第一决定因素；
    • 引用任何数值请附论文版本与表号——实验证据页的每条数值都带出处，可直接链接。
